# 当前陷阱

## 1. 把运行目录当代码目录

本地运行的可变数据在 `.runtime/`；配置位于 `src/trendradar/config/`。不要手工创建第二份 `scripts/` 或 `config/`。

## 2. 只看阶段耗时，不看总耗时

线程、重试和等待可能让阶段加总与墙钟时间不同。验收必须看 `stats.total_elapsed` 和 `stats.budget`。

## 3. 并发日报

同一时段只能有一个 `briefing-pipeline` 锁。看到 `busy` 时不要强行删除锁，先确认 owner 是否仍在运行。

## 4. 空内容误报成功

`silent` 是正常结果；不要用旧产物冒充本轮结果，也不要在 Codex 任务中补写虚构摘要。

## 5. 配置缓存

来源和兴趣配置在进程内缓存。修改配置后应重启当前任务，避免把旧配置的结果误认为新配置结果。

## 6. 翻译服务慢

翻译失败可降级为原文或记录错误，但不能无限等待。超过 180 秒必须让结果显式失败，并在 `timing` 中保留证据。

## 7. 文档漂移

时间表和 JSON 字段只改 `config/plan.json`、`output_protocol.py` 和中心参考文档；Skill 只做引用。
